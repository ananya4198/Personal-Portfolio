# Personal Portfolio

My personal portfolio website, where I share my projects, experience, and a little about who I am. I built it during the UMD App Dev Club web dev bootcamp.

**Live site:** [ananya-nakka.vercel.app](https://ananya-nakka.vercel.app/) 

<img width="1138" height="661" alt="image" src="https://github.com/user-attachments/assets/0506e608-340e-456f-8bc6-838b4ba72a45" />

## What's on the site

- **Projects:** CookieLexic, my competition robot code, Marble Madness, and this site
- **Experience:** my leadership and work experience
- **About & Contact:** a bit about me and how to reach me

## Built with

- React + TypeScript
- Vite
- Bun
- Plain CSS

## How it's organized

Each part of the page is its own reusable React component (`Navbar`, `Hero`, `ProjectCard`, `Experience`, `About`, `Contact`). Project details live in `src/data/projects.ts`, so adding a new project just means adding an entry to that file.
